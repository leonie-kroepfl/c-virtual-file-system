# C Virtual File System

## Overview
A virtual file system implemented in C that simulates basic file and directory operations similar to those found in Linux.

## Features
- Virtual file and directory management
- Linux-like command handling
- Creating and removing files and directories
- Navigating the virtual directory structure
- Listing directory contents
- File system operations implemented in C

## Source Code
- `a5.c` – Implementation of the virtual file system

## Compilation
Compile the program using GCC:

    gcc -Wall -Wextra -o a5 a5.c

## Execution
Run the compiled program:

    ./a5
